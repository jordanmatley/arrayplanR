
# arrayplanR

<!-- badges: start -->
<!-- badges: end -->

The goal of arrayplanR is to quantify performance of deployed receiver arrays and optimize them (or new arrays) for future use. While created as a self-contained package, we prefer to think of it as a 'work package', in which vignettes provide example workflows based on various user conditions/parameters. 

## Installation

You can install the development version of arrayplanR from GitHub with:

``` r
remotes::install_github("jordanmatley/arrayplanR", build_vignettes = TRUE)
library(arrayplanR)
browseVignettes("arrayplanR")
```

## Examples

Please browse vignettes for "DE_array_calculate", "DE_array_optimize_1overlap", and "DE_array_optimize_3overlap" workflows
