
# arrayplanR

<!-- badges: start -->
<!-- badges: end -->

The goal of arrayplanR is to quantify performance of deployed receiver arrays and optimize them (or new arrays) for future use.

## Installation

You can install the development version of arrayplanR from [GitHub](https://github.com/) with:

``` r
remotes::install_github("jordanmatley/arrayplanR")
library(arrayplanR)
```
